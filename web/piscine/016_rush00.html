C Piscine — Rush 00

El primer proyecto en grupo. Una función, rush(x, y), que dibuja un rectángulo de x columnas por y filas con letras en las esquinas y los bordes. Solo con write, y con un fin de semana para ponerse de acuerdo con gente que no conocías el viernes.

  • rush — el doble bucle
  • print_character — qué letra va en cada celda
  • main — las pruebas
  • Ojo: una sola fila o una sola columna
Qué es un rush — Los rushes son los proyectos de fin de semana de la piscine: el sistema te asigna un grupo de dos o tres personas y hay que entregar en el repositorio común antes del domingo por la noche. No hay Moulinette: se defiende en una evaluación en directo donde cualquier miembro del grupo tiene que poder explicar cualquier línea. En el Rush 00 cada grupo recibe una de cinco variantes del mismo dibujo (cambian los caracteres de las esquinas y los bordes). La de este grupo pone A en la esquina superior izquierda y en la inferior derecha, C en las otras dos y B en los bordes — el patrón de la variante que el enunciado llama rush04, aunque el fichero se llame rush00.c. En el pack no está el PDF del enunciado; lo que sigue sale del código. 
$> ./a.out      (rush(5, 3))
ABBBC
B   B
CBBBA
El código es del grupo (la cabecera 42 de los ficheros la firma el compañero, y la última edición de rush00.c es de xalara).

ex00rush

Entrega: ex00/rush00.c, ex00/ft_putchar.c, ex00/main.cAutorizado: write

Recorre el rectángulo fila a fila (i, de 1 a y) y, dentro de cada fila, columna a columna (j, de 1 a x). Cada celda se delega a print_character y al final de cada fila se escribe el salto de línea. Las medidas nulas o negativas no dibujan nada.

void	rush(int x, int y)
{
	int	i;
	int	j;

	if (x <= 0 || y <= 0)
		return ;
	i = 1;
	while (i <= y)
	{
		j = 1;
		while (j <= x)
		{
			print_character(i, j, x, y);
			j++;
		}
		ft_putchar('\n');
		i++;
	}
}

Un detalle que facilita la lectura: los contadores empiezan en 1, no en 0. Así «primera fila» es i == 1 y «última fila» es i == y, que se parece mucho a cómo se describe el dibujo en español.

Qué te obliga a aprender — A pensar una salida en dos dimensiones como una secuencia de bytes: la pantalla no es una cuadrícula, es un flujo de caracteres donde '\n' marca dónde empieza la siguiente fila. El bucle exterior son las filas y el interior las columnas, y confundirlos (o el orden de x e y) es el error típico que la defensa busca.

celdaprint_character

Entrega: ex00/rush00.cAutorizado: write (vía ft_putchar)

Toda la lógica del dibujo está en una cadena de if / else if que decide la letra según la posición. El orden de las condiciones importa: primero las esquinas A, luego las esquinas C, luego cualquier borde, y si no es nada de eso, un espacio.

void	print_character(int i, int j, int x, int y)
{
	if ((i == 1 && j == 1)
		|| (i == y && j == x))
		ft_putchar('A');
	else if ((i == 1 && j == x)
		|| (i == y && j == 1))
		ft_putchar('C');
	else if (i == 1 || i == y
		|| j == 1 || j == x)
		ft_putchar('B');
	else
		ft_putchar(' ');
}
Qué te obliga a aprender — Que una cadena de else if es una tabla de prioridades: la primera condición que se cumple gana. Las esquinas también son borde, así que si la comprobación de borde fuera primero nunca saldría una A ni una C. Separar «qué carácter va aquí» del «recorrer el rectángulo» en dos funciones es además lo que hace que el código sea defendible por cualquiera del grupo.

mainmain

Entrega: ex00/main.cAutorizado: write

El enunciado de los Rush 00 deja que el grupo entregue su propio main, y en la evaluación se cambia por otros valores. El de este grupo prueba casos normales y los bordes: 1×1, una fila, una columna, ceros, negativos y uno grande.

	rush(6, 4);
	rush(1, 1);
	rush(1, 4);
	rush(4, 1);
	rush(2, 2);
	rush(0, 6);
	rush(6, 0);
	rush(0, 0);
	rush(-1, 6);
	rush(6, -1);
	rush(-3, -5);
	rush(123, 42);
Qué te obliga a aprender — A probar antes de que te prueben. Un main que solo llama a rush(5, 3) no demuestra nada; uno con los casos degenerados (0, negativos, 1×N) es la lista de lo que el evaluador va a intentar romper.

ojoUna sola fila o una sola columna

Afecta a: print_character

Con una sola fila (y == 1), la primera y la última fila son la misma. En la última celda se cumplen a la vez «última fila y última columna» (A) y «primera fila y última columna» (C), y como la comprobación de A va primero, gana la A. Lo mismo pasa con una sola columna. Compilado y ejecutado tal cual:

rush(5, 1)      rush(1, 5)
ABBBA           A
                B
                B
                B
                A

Ojo: en esta variante del enunciado, los ejemplos de una fila y de una columna terminan en C (ABBBC y A B B B C en vertical). Con los rectángulos de dos o más filas y columnas (rush(5, 3), rush(4, 4)) la salida es la esperada, y el 1×1 da A.

Qué te obliga a aprender — Que los casos degenerados son donde dos reglas que nunca chocan en el caso general empiezan a solaparse. Cuando una celda es a la vez «primera» y «última», el orden de los if deja de ser un detalle de estilo y pasa a decidir el resultado.
